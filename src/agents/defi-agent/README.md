# AI Defi Assistant

This example agent demonstrates how to create a simple AI assistant that is an expert
in a specified subject.

This agent uses the `asi1-mini` LLM and therefore users will need to create an API
key from: [https://asi1.ai/dashboard/api-keys](https://asi1.ai/dashboard/api-keys)

### Key Concepts Covered  

- A brief introduction to the chat protocol
- Processing contextual prompts to generate responses  

Feel free to modify and experiment with different prompt handling mechanisms! 🚀
